# Windows 离线便携博客 · 富文本图文日记版

适用于 Windows 10 / 11 64 位。自带 Python 运行环境，日常使用无需联网，无需安装数据库或 Python。

## 下载和启动

**推荐：**打开仓库内的 [PortableBlog-Windows-x64.zip](./PortableBlog-Windows-x64.zip)，点击 GitHub 文件页面的 **Download raw file（下载原始文件）** 按钮，下载约 18 MB 的便携包。

也可以使用仓库的 **Code → Download ZIP** 下载整个仓库。下载后完整解压，使用其中的 `PortableBlog` 文件夹即可。

1. 将完整 `PortableBlog` 文件夹放到 `E:\PortableBlog` 或任意可写目录。
2. 双击 `启动博客.bat`，保持启动窗口开启。
3. 浏览器会自动打开；若未打开，请输入启动窗口显示的本地地址（默认 `http://127.0.0.1:8765`）。
4. 点击“管理后台”，首次设置至少 8 位密码。

## 界面与页面架构

根据用户提供的 susushare.com 截图调整：白底留白、横向顶部菜单、窄栏图文首页，以及无边框三栏文章列表。自带原创树林插画，可在后台换成自己的照片。

- **Home**：独立图文首页，标题、文字、图片/视频顺序均可在后台编辑。
- **About / Contact**：独立页面，也可新建更多自定义页面。
- **Blog**：封面、标题、摘要和日期；每页默认 9 篇，带搜索、类目筛选及分页。
- **旅行 / 自定义专题**：通过类目菜单进入，可自行设置为 Deep Japan 等名称。
- **归档 / 媒体**：仍可在菜单设置中增加入口。

## 富文本编辑与字体

文章与独立页面统一使用本地 Quill 编辑器：标题、粗体、斜体、下划线、删除线、引用、列表、代码块、链接、颜色、高亮与对齐；图片、视频可直接插入正文，并提供阅读预览、撤销/重做和 Ctrl+S 保存。

内置 **思源宋体（Noto Serif SC）**，也可选择清晰黑体、等宽字体。每篇文章/页面单独保存字体、字号、行距和段落间距；工具栏还可以调整局部文字。编辑器、字体和样式全部随包携带，无需联网。

![富文本编辑器](./docs/editor-preview.png)

### 表格与复杂公式

在文章或独立页面的正文工具栏下，点击“插入表格”或“插入公式”：

- **表格**：输入行列数（首次插入最多 50 行、12 列），点击单元格填写内容；光标位于表格内时，可用“表格操作”增删行列或删除整张表格。
- **公式**：输入 LaTeX 源码，无需加 `$` 或 `$$`，实时预览后插入；提供分式/根式、积分、矩阵、多行对齐示例。例如 `\frac{a}{b}+\sqrt{x}`。双击已插入的公式可修改源码，支持撤销/重做。
- KaTeX 0.16.22 及字体已内置，编辑、阅读预览、保存后重新编辑均无需联网。公式作为独立段落显示；表格为普通单元格表格，不提供合并单元格操作。

浏览器回归测试：`python3 tests/browser_special_content.py`（另需 Playwright 和 `/usr/bin/chromium`；测试自动创建临时数据库，不修改日记数据）。

旧文章继续按纯文本安全显示；进入新编辑器保存后才转换为富文本。请保存后再离开，当前没有自动保存功能。外部粘贴会过滤不支持的格式，远程图片请先下载再上传。

## 功能

- 可视化富文本文章、草稿与发布、标题和正文搜索。
- 图片、视频、音频、PDF / TXT 附件存储与下载，单个文件最大 1GB。
- 年月归档、类目管理、媒体库，以及独立页面管理。
- 页面编辑支持文字和媒体交错排列；第一张文章图片自动作为列表封面，内嵌媒体不会在文末重复展示。
- 后台配置菜单名称、顺序及目标，以及博客名称、副标题、主题色和背景色。
- 密码修改与数据 ZIP 备份。

视频播放依赖浏览器支持，推荐 MP4（H.264/AAC）；其他编码可保存下载，但不保证直接播放。

## 时间归档、历史发布时间与多标签

- 顶部“时间归档”始终可用：按发布时间查看全部文章，支持最新/最早排序，以及年、月、具体日期筛选。访客看到已发布文章，登录后台后也能查看草稿。
- 编辑文章时可在“发布时间”填写历史日期与时间；列表、阅读页及归档统一使用该时间，原始创建时间保持不变。旧文章自动沿用原日期。
- 一篇文章可勾选多个标签，或在编辑时新建标签；顶部“标签”、博客列表的标签筛选和文章内的标签均可进入相应文章列表。同一篇文章可同时出现在不同标签中。
- 后台“标签管理”可添加或删除标签。删除标签会移除所有文章的该标签关联，不删除文章。编辑文章可单独调整标签；后台文章列表和登录后的阅读页支持确认后直接删除文章，媒体仍保留在媒体库。
- 标签最多 40 字，每篇文章最多 20 个。类目功能继续保留。数据与备份均包含历史时间和标签；升级前请先导出备份。

浏览器回归：`python3 tests/browser_archive_tags.py`（Playwright + Chromium，临时数据库）。覆盖日期筛选、多标签索引、历史日期与标签修改、标签删除和文章删除。

## 已使用旧版时，如何升级

1. 在旧版导出备份并关闭启动窗口。
2. 把新版解压到一个新目录，保留旧目录以便回退。
3. 将旧版的整个 `data` 文件夹复制到新版 `PortableBlog` 内。
4. 启动新版。原文章、媒体与密码保留，新数据库字段自动初始化，旧文本保持兼容。

自定义菜单与颜色会保留，旧版未修改的默认菜单/配色会更新。若保留了自定义菜单，请在后台添加 `Blog | 博客` 等需要的新入口。请勿使用旧程序打开升级后的数据；回退用升级前备份。

## 整目录迁移

先保存内容并关闭启动窗口，再复制**整个 PortableBlog 文件夹**到另一台 Windows 10/11 64 位电脑，双击启动即可。路径和盘符可以改变。

`data` 文件夹在首次运行时自动创建，包含文章、媒体、设置和密码校验信息。请勿删除，切勿在运行中直接复制。后台密码不对磁盘文件加密；数据备份应妥善保管。

详细操作见 [使用说明](./PortableBlog/使用说明.txt)，测试范围及限制见 [验证记录](./PortableBlog/验证记录.txt)。
