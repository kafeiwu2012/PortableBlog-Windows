离线便携博客 v3 · 富文本编辑 · 验证记录

参考依据：用户提供的 susushare.com 首页、文章列表及页脚截图；未取得网站源码。
实现内容：白底留白、顶部导航、650px 图文首页、独立页面、三栏文章列表、分页、页脚联系入口。
默认树林插画为本项目生成的 SVG，不含参考站照片或正文。

本轮在 Linux 云端以 Python 标准库服务与 Chromium 完成：
- 首次设密、后台登录；独立页面编辑、媒体上传及图文交错标记插入。
- 顶部 Home / About / Blog / Contact / 旅行导航。
- 桌面三栏文章布局，12 篇测试文章按 9 / 3 分页、上一页/下一页和搜索。
- 文章地址标记刷新后仍打开相同文章。
- 首页/列表手机端 390px 宽度，无横向溢出；浏览器无 JavaScript 异常。
- 浏览上述页面及后台操作，无任何外部网络请求。
- 草稿页面及其独占媒体对未登录访客隐藏；发布后媒体可读取。
- 被页面引用的媒体不可删除；首页不可删除；菜单引用中的页面不可删除。
- 页面标识、引用媒体及分页参数校验。
- H.264 视频上传、元数据加载、实际播放与定位。
- 页面和媒体的 ZIP 一致备份、SQLite 完整性检查及另一目录恢复启动。
- 旧版数据库升级保留文章、密码与自定义菜单/配色。
- 新页默认内容只初始化一次，已删除页面不会在重启后重新出现。

原版已验证能力：文章草稿/发布、附件、设置、密码修改/会话失效、来源校验等。

便携包不包含测试数据、用户数据或预设密码。首次启动自动创建 data。
Windows x64 runtime 为自带 Python 3.12.10，来源和许可见使用说明及 runtime/LICENSE.txt。

限制：云端为 Linux，未在真实 Windows 上双击 BAT 或执行随包的 python.exe。
Windows 启动、浏览器自动打开及目标电脑的视频编码支持仍需实际验证。
