离线便携博客 · Windows 10 / 11 64 位

一、第一次使用
1. 将整个 ZIP 解压到 E:\PortableBlog，或任意有写入权限的本地目录。
   不要直接在压缩软件内运行，不要只复制启动文件。
2. 双击“启动博客.bat”（或 Start-Blog.bat）。保持黑色窗口开启。
3. 浏览器会自动打开。如没有打开，在浏览器输入 http://127.0.0.1:8765
4. 点击“管理后台”，设置至少 8 位密码。
5. 在“文章”中写文章、选类目、上传或选择附件，再保存为草稿或已发布。

二、新版页面架构（参考用户提供的 susushare.com 截图）
- Home：650px 窄栏图文首页，标题、欢迎语、大图、介绍文字可自行编辑。
- About / Contact：独立页面；可增加更多自定义介绍页面。
- Blog：桌面端三栏封面、标题、摘要及日期，搜索、类目筛选和分页。
- 旅行：类目专题入口，可改名为 Deep Japan 或任何自己需要的专题。
- 手机端自动适配。顶部菜单、页面内容和页脚文案均可后台修改。

后台“独立页面”的用法：
1. 编辑 Home（标识 home）或 About / Contact，填写标题与正文。
2. 将光标放到正文中，在右侧上传文件或点击已有媒体，直接插入可见的图片、视频或文件链接。
3. 文字和媒体可交错排列，不需要手写标记。旧版标记在进入新编辑器后会自动转换。
4. 右侧可插入自带的原创树林插画，也可换成自己的照片。
5. 页面保存为“已发布”才对普通浏览页面可见；草稿仅登录后台后能预览。
6. 新建页面的标识用小写字母、数字和短横线，例如 travel-guide。
7. 到“类目 / 菜单 / 界面”，菜单每行写“名称 | 目标”，例如：
   Home | 首页
   About | 页面:about
   Blog | 博客
   Contact | 页面:contact
   Deep Japan | 类目:旅行
   归档 | 归档
   相册 | 媒体
8. 第一张文章图片自动用作 Blog 列表封面。每页文章数可在界面设置调整。

三、原有功能
- 可视化富文本文章、草稿、发布、编辑、删除、标题和正文搜索。
- 图片、视频、音频、PDF 和 TXT 原文件存储，单文件最大 1GB。
- 图片与视频可直接插入正文；额外勾选的附件显示在文末，文内媒体不会重复展示。
- 可视化富文本排版：标题、加粗、斜体、下划线、删除线、引用、列表、代码块、链接、颜色、高亮和对齐。
- 内置思源宋体（Noto Serif SC），可切换清晰黑体及等宽字体；支持局部文字字体和大小设置。
- 每篇文章/页面可独立设置正文字体、16 至 24px 字号、1.6 至 2.2 倍行距和段落间距。
- “阅读预览”仅预览当前排版，不发布；Ctrl+S 保存；工具栏支持撤销和重做。
- 支持从剪贴板粘贴图片文件上传；外部粘贴内容会过滤不支持的格式，远程图片需先下载到本地再上传。
- 编辑器不会自动保存未提交内容；离开前请点击保存。
- 本版本不做视频转码或 Markdown 语法渲染。
- 以年/月和类目浏览归档；媒体库管理与原文件下载。
- 后台配置类目、顶部菜单名称/顺序/目标、站点名称、副标题及主题/背景颜色。
- 删除类目不删除文章；正在被文章引用的附件不能直接删除。
- 草稿及未发布附件只在后台可见。
- 后台密码修改、退出、数据 ZIP 备份。
- 所有界面、程序和数据库均在本地，无 CDN、云数据库或在线登录依赖。

四、换电脑 / 迁移
1. 保存编辑内容，关闭启动时的黑色窗口。不要在博客运行时直接复制。
2. 复制整个 PortableBlog 文件夹到 U 盘、移动硬盘或另一台电脑。
3. 在另一台 Windows 10/11 64 位电脑上双击“启动博客.bat”。
路径和盘符可以改变，不需要安装 Python、数据库或下载依赖。
程序仅监听 127.0.0.1，不向局域网或公网发布。
请勿让两台电脑同时通过共享盘使用同一份 data 文件夹。

五、数据与备份
程序会自动在本目录创建 data 文件夹：
  data\blog.sqlite3   文章、独立页面、类目、菜单、界面设置和密码校验信息
  data\media\        图片、视频等原文件
runtime 为自带的官方 Python 运行环境。不要删除。
后台顶部“导出数据备份”会生成一致的数据库快照，并包含媒体文件。
此备份只含数据，不含程序与 runtime；完整迁移请复制整个博客目录。
恢复备份：关闭程序，先备份当前 data，然后将当前 data 移到别处，
把备份 ZIP 内的 data 文件夹解压到博客根目录，再启动。
备份创建期间媒体写入会等待，视频很多时备份可能较慢。
数据库与媒体文件未加密。后台密码不能防止拥有文件访问权限的人读取数据。
请勿丢失密码；本版本未提供自动密码找回。

六、从旧版升级（已有文章时）
1. 先在旧版后台导出备份，并关闭旧版启动窗口。
2. 将新版解压到一个新目录，不要删除旧版。
3. 把旧版整个 data 文件夹复制到新版 PortableBlog 文件夹内。
4. 启动新版，原文章、媒体和密码会继续使用，数据库自动增加需要的字段。
   原文按纯文本安全显示；进入富文本编辑器并保存后，才会转换为富文本格式。
5. 原先自定义的菜单与颜色会保留；如仍为旧版默认菜单/配色，会升级为新默认样式。
6. 若保留的是自定义菜单，需自己添加“Blog | 博客”等需要的新页面入口。
7. 确认内容都正常后，再决定是否移除旧版。不要把旧程序指向已升级的数据，回退时使用升级前备份。

七、故障处理
- 端口占用：先关闭之前的博客窗口，不能同时重复启动。
  如确需改端口，可在命令提示符中运行：
    set BLOG_PORT=8766
    Start-Blog.bat
  浏览器使用启动窗口显示的地址。
- 保存失败：检查剩余磁盘空间及文件夹写入权限。
- 视频无法播放：浏览器支持与视频编码有关，推荐 MP4（H.264 视频/AAC 音频）；
  MOV 等文件可以保存和下载，但不保证浏览器直接播放。可下载后用本地播放器打开。
- 如 Windows 安全软件询问，请核实文件来源后按你自己的设备策略处理。
- 若缺失 DLL 或启动失败，请保留窗口中的报错用于排查；Windows 启动仍需在你的电脑验证。

表格与复杂公式
- 正文工具栏下点击“插入表格”，输入行数和列数后插入。点击单元格输入内容。
- 先点击表格单元格，再用“表格操作”插入或删除行列，或删除整张表格。
- 点击“插入公式”，输入 LaTeX（无需美元符号），可选择分式、积分、矩阵、多行对齐示例。
- 公式预览正确后点击“插入”；双击正文中的公式可修改源码。格式错误时会提示，请修正再插入。
- 表格和公式都支持阅读预览、保存和重新编辑；KaTeX 与字体全部内置，无需联网。
- 公式为独立段落；暂不提供行内公式及合并单元格操作。
